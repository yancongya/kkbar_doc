# 主题与外观

## 🎨 UI 设计理念

![首页](/assets/images/uisettings.webp)

**简约至上**：

- **无文案按钮**：工具栏按钮使用纯图标设计，节省空间，视觉更简洁
- **渐进式披露**：复杂功能面板默认折叠，按需展开，避免信息过载
- **即时反馈**：所有操作都有视觉反馈（悬停、点击、拖拽）

**现代化交互**：

- **响应式设计**：面板根据窗口宽度自动调整布局
  - ≥ 480px：正常布局
  - 360–479px：紧凑布局
  - < 360px：超窄布局
  - < 260px：极窄布局（隐藏文字，仅显示图标）
- **动态尺寸**：图标大小和间距实时可调，拖动滑块时面板透明预览
- **快捷键系统**：支持 Ctrl/Alt/Shift 组合，一个按钮可触发多种动作

## 图标设置

### 图标大小

拖动滑块调整按钮图标大小（10-50）。

拖动大小、间距、描边或圆角滑块时，设置面板会自动变为透明，方便你直接预览主页按钮的实际效果。松开滑块后面板恢复正常。

拖动**图标大小**或**图标间距**滑块时，工具栏上会实时显示网格占位框预览，帮助你直观了解按钮的排列布局。松开滑块后占位框消失。

### 图标间距

拖动滑块调整按钮之间的间距（0-30）。

### 按钮描边

拖动滑块调整按钮外框描边宽度（0-3），支持 0.1 级无极调节。

- 描边为 0 时隐藏外框
- 描边颜色随主题自动适配（ae-native / light-modern 使用系统边框色，obsidian 使用蓝色调，nord 使用 nord 色系）
- 描边渲染在按钮填充和图标之上，不会导致图标偏移
- 开启「透明」模式时，描边自动隐藏

### 按钮圆角

拖动滑块调整按钮圆角比例（0-50%）。

- 圆角为 0 时使用默认值（随图标大小自动缩放，最大 12px）
- 圆角大于 0 时，以按钮实际短边的百分比计算圆角半径，不同尺寸的按钮同一设置视觉比例一致
- 开启「透明」模式时，圆角设置不生效（按钮背景透明，圆角无意义）

## 导航栏

导航栏位于面板顶部，包含以下固定按钮：

| 按钮 | 功能 |
|------|------|
| 分类下拉 | 切换当前显示的分类 |
| 日志 | 打开日志面板，查看执行记录 |
| 切换视图 | 卡片网格 ↔ 单列列表切换 |
| 关于 | 打开关于页面（仅免费版显示） |
| 设置 | 打开设置面板 |

可在设置中开启或关闭导航栏显示。

## 布局模式

| 模式 | 说明 |
|------|------|
| 换行 | 按钮自动换行排列 |
| 单行 | 按钮单行水平排列 |
| 垂直 | 按钮垂直排列 |

通过首页导航栏或分类切换器长按菜单进行切换。

### 动态网格布局

在**换行**模式下，工具栏会根据面板宽度自动调整每行的按钮数量：

- 面板较宽时，每行显示更多按钮
- 面板较窄时，按钮自动换行到下一行
- 面板高度随内容自动调整，无需滚动

调整图标大小或间距时，网格列数会实时重新计算，确保按钮始终整齐排列。

## 分类切换器

首页按钮网格的固定位置有一个分类切换器按钮，显示当前分类的图标。

### 点击操作

| 操作 | 效果 |
|------|------|
| 点击 | 切换到下一个分类 |
| Ctrl + 点击 | 打开设置面板 |
| Shift + 点击 | 打开日志面板 |
| Alt + 点击 | 打开关于页面 |
| Ctrl + Shift + 点击 | 切换视图模式（卡片/列表） |

### 长按弹出菜单

**长按**分类切换器按钮（300ms）会弹出快捷操作菜单，包含：

- 切换分类
- 打开设置
- 打开关于
- 打开日志
- 切换视图

---

## 长按按钮菜单

首页中，**长按任意按钮**（300ms）会弹出该按钮下所有快捷动作的菜单，方便单手操作。

### 两种显示模式

| 模式 | 说明 | 切换方式 |
|------|------|---------|
| 面板模式（默认） | 居中垂直列表，显示动作名称和快捷键 | 设置中关闭"环形菜单" |
| 环形菜单模式 | 图标围绕按钮呈环形排列，鼠标移动选中 | 设置中开启"环形菜单" |

在设置面板的开关区域，可以通过 **环形菜单** 开关切换这两种模式。

## 响应式布局

设置面板会根据窗口宽度自动调整布局，确保在窄面板中也能正常显示：

| 宽度范围 | 调整内容 |
|---------|---------|
| ≥ 480px | 正常布局 |
| 360–479px | 紧凑布局：开关缩小、间距减小、主题/数据按钮网格保持 4 列 |
| < 360px | 超窄布局：开关滑块进一步缩小、间距最小化 |
| < 260px | 极窄布局：开关文字隐藏（仅显示滑块）、数据按钮文字隐藏（仅显示图标） |

面板高度变小时，设置页面内容会自动滚动，各区域（滑块、开关、主题选择、数据操作、数据库路径）按顺序排列，不会互相遮挡。
